# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

给剧场灯光师使用的灯位与 Cue 表管理前端，适合排练期间快速调整：灯位、Cue 与演出版本备注互相关联，不再脱节。

## 功能

- **舞台平面灯位图**：俯视舞台/观众席布局，灯具按类型着色，光晕大小实时反映当前 Cue 中该灯亮度；虚线圈表示焦点待确认。
- **灯具编辑**：维护灯具编号、通道号、色片、焦点位置、亮度预设、灯光类型与灯位坐标，修改后同步更新灯位图与当前场景；删除灯具会同步撤出所有 Cue。
- **Cue 列表与调序**：↑/↓ 调整触发顺序，整条 Cue 的各灯通道与亮度随之一并移动；点击 Cue 切换当前场景。
- **当前场景预览**：编辑 Cue 名称/场次，拖动滑杆写入各灯亮度（灯位图同步变化），按灯具预设一键加入或移除通道。
- **类型筛选**：按面光/侧光/逆光/效果光筛选后，灯位图与 Cue 列表只显示相关灯位与包含该类型灯具的 Cue。
- **演出版本备注**：版本A/版本B 切换显示对应备注；备注可引用 Cue（点击引用跳转）。被引用的 Cue 必须先在列表中「解除全部引用」才能移除。
- **指标**：灯具数量、Cue 数量、当前场景、待确认焦点（未确认焦点的灯具实时计数）。

## 技术栈

React + Vite + TypeScript
